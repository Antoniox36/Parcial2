## Descripción del Proyecto
Aplicación interactiva desarrollada en **PyQt5** con integración de **Pandas** y **Matplotlib** para el análisis, inspección y visualización del inventario de productos en 5 sucursales (San Salvador, Santa Ana, San Miguel, La Libertad y Sonsonate).

## Estructura de Archivos
* `generador_datos.py`: Creación del inventario e inspección estadística con Pandas.
* `graficos.py`: Módulo de gráficos interactivos con Matplotlib.
* `main.py`: Interfaz gráfica principal en PyQt5.
* `inventario.csv`: Dataset del inventario comercial.
* `informe_consultoria.pdf`: Informe ejecutivo de consultoría.
